ECHO REALMS: THE WITNESS
Prototype v0.8 — Forest Haven

A ritual simulation where you witness, not control.

═══════════════════════════════════════════════════════════

LAUNCH:
  Double-click EchoRealms.exe

SAVES:
  Automatically stored in saves/save_echo_realms.json
  Press F5 to save manually
  Press F9 to load
  
CONTROLS:
  WASD        - Move
  Click NPC   - Select
  E           - Witness (when near)
  G           - Glyphs
  D           - Dreams (Night only)
  R           - Rituals
  J           - Journal
  C           - Codex
  F5          - Save
  F9          - Load
  ESC         - Close panels
  Q           - Quit

WHAT TO EXPECT:
  • 22-second time slices (Dawn/Day/Dusk/Night)
  • 7-day seasons (4 seasons per year)
  • Witnessing NPCs earns resonance + unlocks codex pages
  • Rituals trigger automatically on specific days/slices
  • Dreams can only be seeded at Night
  • Pulse variables shape the realm's atmosphere

═══════════════════════════════════════════════════════════

TIPS:
  • Green ring around NPC = in range to witness
  • Red ring = too far, walk closer
  • Yellow arrow points toward distant selected NPC
  • Time flows automatically (pauses when panels open)
  • Rituals show 3-second warning before panel opens
  • Journal shows newest entries first
